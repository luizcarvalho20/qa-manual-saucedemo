# QA Manual - SauceDemo

Projeto prático de QA Manual utilizando o SauceDemo (Swag Labs) como sistema sandbox para validação de fluxos funcionais de e-commerce.

## Objetivo
Demonstrar habilidades práticas em QA Manual, incluindo:
- análise funcional do sistema
- definição de escopo de teste
- elaboração de cenários
- criação de casos de teste
- execução manual
- coleta de evidências
- documentação de resultados
- escrita de cenários BDD/Gherkin

## Sistema testado
- SauceDemo (Swag Labs)
- URL: https://www.saucedemo.com/

## Escopo coberto
- Login
- Catálogo de produtos
- Carrinho
- Checkout

## Estrutura do projeto
- `docs/` → documentação de apoio e relatórios de execução
- `test-cases/` → casos de teste manuais por módulo
- `bdd/` → cenários em Gherkin
- `evidencias/` → capturas de tela dos testes executados
- `bug-reports/` → registro de bugs ou resumo da validação

## Artefatos criados
- Mapeamento inicial do sistema
- Casos de teste de login
- Casos de teste de catálogo
- Casos de teste de carrinho
- Casos de teste de checkout
- Relatórios de execução por módulo
- Cenários BDD

## Ferramentas utilizadas
- Git
- GitHub
- Visual Studio Code
- Markdown
- Google Chrome

## Resultado
Os fluxos principais do sistema foram documentados, executados manualmente e validados dentro do escopo definido para o projeto.
