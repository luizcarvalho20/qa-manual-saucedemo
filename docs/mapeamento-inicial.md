# Dia 1 - Mapeamento Inicial do SauceDemo

## Objetivo
Mapear funcionalidades principais do sistema e levantar cenários iniciais de teste.

## Funcionalidades identificadas
- Login
- Logout
- Listagem de produtos
- Carrinho
- Checkout

## Riscos iniciais
- Falhas de login
- Carrinho inconsistente
- Problemas no checkout
- Mensagens de erro inadequadas

## 10 cenários iniciais
1. Validar login com credenciais válidas
2. Validar login com senha inválida
3. Validar campos obrigatórios no login
4. Validar listagem de produtos
5. Validar adição de item no carrinho
6. Validar remoção de item do carrinho
7. Validar acesso ao checkout
8. Validar preenchimento obrigatório do checkout
9. Validar finalização de compra
10. Validar logout
